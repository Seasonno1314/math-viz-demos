## 站点一 · 小学「数形结合」动态演示视频库（仓库根）

### 👉 [**打开在线视频库**](https://Seasonno1314.github.io/math-viz-demos/)

面向小学的 18 段数学原理动态演示动画。核心思路：**数形结合** —— 把抽象的数量关系画成看得见的图形，让原理"看得见、摸得着"。

- 卡片是整片循环的 **WebP 动图预览**（自动播放，无需点击）
- 点一下预览即可播放 **1080p 原片**，也可以直接下载 mp4
- 免安装、免登录，浏览器即开即用

| 🎬 旗舰轮播 | Hero 区大画幅展映 4 支旗舰案例（高斯求和 · 圆的面积 · 可能性转盘 · 分数乘法），自动切换 + 进度条 + 键盘操作 |
| 🏷 分类筛选 | 运算律 / 分数 / 行程问题 / 图形与几何 / 统计与可能性 / 思维拓展，带数量角标 |

| 🌙 降级适配 | 触屏关倾角、`prefers-reduced-motion` 全局降级、离线字体回退 |

## 站点二 · 四学段「交互可视化」案例库（`k12/`）

### 👉 [**打开四学段交互库**](https://Seasonno1314.github.io/math-viz-demos/k12/)

32 个**可以动手拖、动手点**的交互案例，从小学一路铺到本科。每个案例都配：

- 🖱 **可交互 HTML**（单文件、零依赖，拖滑块 / 拖点看变化）
- 🎥 **1080p MP4** 讲解成片
- 🌀 **WebP 动图预览**与封面图

| 学段 | 数量 | 代表案例 |
|---|---|---|
| 小学 | 6 | 比与比例 · 配方缩放 ／ 平均数 · 移多补少 ／ 平移与旋转 |
| 初中 | 8 | 勾股定理面积拼合 ／ 一次函数三表征联动 ／ 二次函数 · 抛物线探索 |
| 高中 | 9 | 导数：割线逼近切线 ／ 正弦曲线：单位圆展开 ／ ε-δ 极限入门 |
| 本科 | 9 | 黎曼和逼近定积分 ／ Taylor 展开逐阶逼近 ／ 傅里叶级数 · 波叠加 |

完整的 32 条清单（含每个案例的核心概念与交互说明）见 **[k12/README.md](k12/README.md)**。

## 目录结构

```
math-viz-demos/
├── index.html            # 站点一：小学「数形结合」视频库（仓库根）
├── webp/                 #   18 个动图预览
├── mp4/                  #   18 个 1080p 原片
├── images/               #   作者二维码、一知未来 logo
├── k12/                  # 站点二：四学段「交互可视化」案例库
│   ├── index.html        #   四学段库主页
│   ├── cases.js          #   32 个案例的索引数据
│   ├── cases.json        #   同上（JSON 源）
│   └── math-cases/       #   32 个案例：可交互 HTML + MP4 + WebP + 封面
├── README.md             # 本文件（中文）
├── README.en.md          # English
└── LICENSE               # MIT License
```

> 说明：为控制仓库体积，四学段库仅收录页面实际读取的资源（可交互 HTML、1080p MP4、WebP 动图、封面 JPG），未收录 GIF 预览与关键帧 PNG 等中间产物。

## 本地预览

纯静态站点，无需构建、无需依赖。任选一种：

```bash
# 方式一：直接双击打开（最简单）
index.html          # 小学站
k12/index.html      # 四学段站

# 方式二：起一个本地静态服务器（推荐，路径行为与线上一致）
python -m http.server 8000
# 然后访问 http://localhost:8000/         → 小学站
#         http://localhost:8000/k12/      → 四学段站
```

## 技术栈

- 动画：**[Manim CE](https://www.manim.community/)** 渲染，1920×1080 / 30fps
- 动图预览：**Animated WebP**（640px / 12fps / 整片循环），体积约为 GIF 的 1/3
- 站点：单文件 HTML + 原生 JS + CSS，**零构建、零依赖、离线可用**
- 设计系统（两站通用 · 深空实验室风 · 黑金克制体系）：

```css
--bg-0: #0B1120;   --bg-1: #101A31;        /* 深空底 */
--gold: #E8B964;                           /* 全站唯一强调色 */
--txt: #EAEDF4; --txt-2: #9CA8C0; --txt-3: #5D6A85;
--line: rgba(255,255,255,.09);             /* 发丝线 */
字体: Space Grotesk + PingFang SC / 微软雅黑 + JetBrains Mono
```
