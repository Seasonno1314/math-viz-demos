# 小学数学 · 数形结合动态演示视频库

面向小学的 18 段数学原理动态演示动画（Manim 渲染，1080p / 30fps / H.264）。

核心思路：**数形结合** —— 把抽象的数量关系画成看得见的图形，让原理"看得见、摸得着"。

## 技术说明

- 动画由 [Manim](https://www.manim.community/) 渲染，分辨率 1920×1080 / 30fps。
- 动图预览为 Animated WebP（640px / 12fps / 整片循环），体积约为 GIF 的 1/3。
- 目录结构：
  - `index.html` —— 在线看板（GitHub Pages 根目录）
  - `webp/` —— 18 个动图预览
  - `mp4/` —— 18 个 1080p 原片
- 使用：直接打开 `index.html`，或点击 mp4 下载到本地播放。
