## About this site

**32 hands-on visualization cases** spanning primary school through undergraduate mathematics.
Unlike passive animations, every case here is **interactive** — drag a slider or a point and the principle moves.

Each case ships with four artifacts:

| Artifact | Description |
|---|---|
| 🖱 **Interactive HTML** | Single file, zero dependency, double-click to open; drag sliders / points |
| 🎥 **1080p MP4** | Narrated video, 1920×1080 / 30fps |
| 🌀 **Animated WebP** | Looping card preview, ~1/3 the size of an equivalent GIF |
| 🖼 **Cover JPG** | Thumbnail for lists and sharing |

## Repository layout

```
k12/
├── index.html          # Library home (single file, zero dependency)
├── cases.js            # Index of the 32 cases (loaded by the page)
├── cases.json          # Same, as JSON source
└── math-cases/
    ├── 小学/   6 cases (Primary)
    ├── 初中/   8 cases (Middle School)
    ├── 高中/   9 cases (High School)
    └── 本科/   9 cases (Undergraduate)
         <case>/
         ├── index.html                  # Interactive page (self-contained)
         ├── metadata.json               # Case parameters & recording config
         └── out/
             ├── C-XXX.mp4               # 1080p video
             ├── C-XXX-preview.webp      # Animated preview
             └── C-XXX-preview-cover.jpg # Cover
```

> Only the assets the pages actually load are committed; GIF previews and keyframe PNGs are excluded to keep the repo lean.

## Run locally

```bash
# Option 1: open the file directly
k12/index.html

# Option 2: local static server (recommended)
python -m http.server 8000
#   then open http://localhost:8000/k12/
```

## Tech notes

- Each case page is a **self-contained single-file HTML** with no local asset references — easy to redistribute, embed in courseware, or drop into an LMS.
- Videos are rendered with [Manim CE](https://www.manim.community/) at 1920×1080 / 30fps.
- The home page is a zero-build single-file app: no bundler, no framework, no external JS.
- Keyboard navigation and `prefers-reduced-motion` degradation are supported.
