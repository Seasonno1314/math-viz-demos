## 关于本站

这里收录 **32 个可以动手操作**的数学可视化案例，覆盖小学、初中、高中、本科四个学段。
与「看动画」不同，这里的每个案例都**可以拖、可以点**——拖动滑块或动点，原理自己动起来。

每个案例都配齐四件套：

| 组成 | 说明 |
|---|---|
| 🖱 **可交互 HTML** | 单文件、零依赖，双击即开；拖滑块 / 拖动点看变化 |
| 🎥 **1080p MP4** | 讲解成片，1920×1080 / 30fps |
| 🌀 **WebP 动图** | 卡片循环预览，体积约为 GIF 的 1/3 |
| 🖼 **封面 JPG** | 列表与分享用图 |

## 技术说明

- 案例页面为**单文件自包含 HTML**，不引用任何本地资源，可单独分发、嵌入课件或 LMS。
- 视频由 [Manim CE](https://www.manim.community/) 渲染，1920×1080 / 30fps。
- 主页 `index.html` 为零构建单文件应用：无打包器、无框架、无外部 JS 依赖。
- 支持键盘操作与 `prefers-reduced-motion` 降级。
