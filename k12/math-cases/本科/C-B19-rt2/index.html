课堂三问

  1. 有理数世界里为什么有"洞"？逼近序列每一项都是有理数，为什么目标位却不被任何刻度占据？
    参考答案把 ℚ 看作"刻度世界"：√2 恰好落在两条可公度刻度之间。序列 xₙ=1,1.4,1.41,1.414… 每一步都是有理数、彼此越靠越近（柯西序列），但它的极限位置在 ℚ 里不存在——那个空位就是洞。
  2. 完备性到底给了我们什么？
    参考答案完备性（连续性公理）断言：ℝ 中柯西序列必收敛、单调有界必收敛。直觉上就是"数轴上没有洞"——任何逼近过程都有一个真实存在的极限点作为归宿，我们才能写 √2 = lim xₙ 并把它当普通数参与运算。
  3. 保留 n 位小数时误差为什么 < 10⁻ⁿ？有限精度能"到达"√2 吗？极限算什么？
    参考答案截断误差 0 ≤ √2−xₙ < 10⁻ⁿ：想要多近就有多近，但有限步内永远到不了。误差条逐项递减到 10⁻⁸ 量级，直观展示了"收敛但不等于"——极限是过程之外的实体，完备性保证它存在。
