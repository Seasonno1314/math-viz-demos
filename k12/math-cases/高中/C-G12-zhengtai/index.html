课堂提问（3 问）

为什么曲线下总面积 = 1？数

f(x) 是「概率密度函数」：X 落在实数轴某处的总概率必须是 1，所以 ∫−∞+∞ f(x)dx = 1。这正是直方图逼近的终点——把柱数 n 拉大、柱子铺满整个区间， 直方图总面积就越来越接近 1（本图用柱宽×柱高求和来逼近积分）。「面积 = 概率」的根源在于： 所有可能结果发生的概率加起来必须等于 1。

σ 变大，曲线怎样变化？形

σ 变大 → 曲线变矮、变宽（更「胖」更扁平）：最高点 1/(σ√(2π)) 变小，尾部更厚、数据更分散。 拖 σ 滑块即可看到钟形曲线与直方图一起「塌矮摊开」，但曲线下的总面积始终保持为 1——面积守恒。 σ 变小的反面是曲线变「尖」变「瘦」，峰值更高。

为什么 68% / 95% / 99.7% 不随 μ、σ 改变？动

标准化：令 Z = (X−μ)/σ，则 Z ~ N(0,1)，区间 μ±kσ 恰好对应 Z ∈ (−k, k)。 μ 只负责左右平移（面积不变），σ 只负责整体缩放（比例不变），所以 P(μ−σ<X<μ+σ) 恒 ≈ 68.27%。 切换三个区间按钮并拖动 μ、σ 滑块：阴影面积数值几乎纹丝不动——这就是「面积与 μ、σ 无关」的直观证明。
